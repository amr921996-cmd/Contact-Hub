# Contact Hub 📇

A web app for managing contacts, built with HTML, CSS, and JavaScript.

🔗 **[Live Demo](https://amr921996-cmd.github.io/Contact-Hub/)**

## ✨ Features
- Add new contacts
- Delete contacts
- Edit contacts
- Search through contacts
- Data saved in the browser (localStorage)
- Responsive design for mobile screens

## 🛠 Built With
- HTML5
- CSS3
- JavaScript (Vanilla)
